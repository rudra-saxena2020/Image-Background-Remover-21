# MIRAGE GOOGLE COLAB GPU IMAGE GENERATION WORKER

## Objective

Build a complete Google Colab notebook that acts as the GPU image-generation worker for the Mirage Store product photography system.

The Colab notebook must be capable of taking real product reference images and generating high-quality e-commerce images with realistic human models while preserving the actual product.

The notebook is NOT the Mirage frontend.

The notebook is the GPU inference backend.

Architecture:

```text
MIRAGE / REPLIT
       |
       | HTTPS API
       v
GOOGLE COLAB GPU WORKER
       |
       +-- Product preprocessing
       +-- AI image generation
       +-- BiRefNet
       +-- Product validation
       +-- Human/anatomy validation
       +-- Real-ESRGAN
       |
       v
FINAL IMAGES
       |
       v
MIRAGE
```

==================================================

1. PRIMARY PRODUCT REQUIREMENT
   ==================================================

The most important requirement is:

THE PRODUCT MUST NOT BE REDESIGNED.

If the user uploads a handbag, the generated image must contain the same handbag.

Preserve:

* exact shape
* exact silhouette
* exact proportions
* exact color
* exact texture
* exact material
* exact stitching
* exact hardware
* exact clasp
* exact handles
* exact straps
* exact buckles
* exact logo
* exact pattern
* exact construction

Do NOT accept a visually similar product.

A generic burgundy handbag is NOT the uploaded burgundy handbag.

This distinction is critical.

==================================================
3. PRODUCT PREPROCESSING
========================

For every source image:

1. Load image.
2. Validate resolution.
3. Detect product.
4. Remove background using BiRefNet.
5. Create transparent RGBA product image.
6. Refine edges.
7. Preserve thin straps, handles and hardware.
8. Save product mask.
9. Save product metadata.

Directory:

```text
/data/products/<product_id>/
    source/
    masks/
    extracted/
    metadata/
```
