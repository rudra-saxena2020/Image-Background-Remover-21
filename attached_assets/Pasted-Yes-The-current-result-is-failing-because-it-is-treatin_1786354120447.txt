# REPLIT MASTER PROMPT: AI PRODUCT + HUMAN MODEL GENERATION ENGINE

Build and enforce a production-grade AI product photography system for e-commerce fashion products.

The system must take uploaded product reference images and generate **high-quality, photorealistic product photography with an appropriate human model when the product category requires one**.

The output must look like a professional luxury fashion campaign, not an AI-generated cutout, mannequin, collage, or generic stock photo.

The system must support transparent-background output.

---

# 1. CORE OBJECTIVE

The user uploads **1 to 6 product reference images**.

The system must:

1. Analyze all uploaded product images.
2. Detect the product category.
3. Determine whether a human model is required.
4. Determine the appropriate model type.
5. Create a realistic model appropriate for the product.
6. Preserve the exact uploaded product.
7. Place the product naturally on/in the model's body when required.
8. Generate a professional pose appropriate to the product.
9. Generate a premium commercial photograph.
10. Remove the complete background.
11. Return a **true transparent PNG**.
12. Upscale the final image.
13. Run quality checks.
14. Automatically regenerate failed images.

# 4. HUMAN MODEL REQUIREMENT

When `model_required = true`:

**THE HUMAN MUST BE PRESENT.**

The generated image is invalid if:

* No model exists
* Model is only partially generated when a full model is required
* Product is floating
* Product is pasted onto the model
* Product is not physically interacting with the model
* Model looks like a mannequin
* Model looks like a plastic CGI character
* Model has obvious AI artifacts

Do not silently fall back to product-only generation.

Do not silently generate a cutout product.

If the model generation fails, mark the frame as `FAILED_MODEL_GENERATION` and retry.

# 6. FACE QUALITY
