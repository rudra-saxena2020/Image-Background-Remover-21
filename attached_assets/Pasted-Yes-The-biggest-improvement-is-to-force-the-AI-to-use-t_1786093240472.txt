## One more thing for Replit

If your backend is currently sending only a **text prompt** to HiDream/OpenAI, this prompt alone will **not** make it use the source images.

Your backend must send the uploaded images as **image inputs** to the generation model (image-to-image or editing API), not just upload them to storage.

For example, the workflow should be:

```
Upload Product Images
        ↓
Extract Product Features
        ↓
Send Images + Prompt to Image Generation Model
        ↓
Generate Edited Scene (not a new product)
```

If the source images are **not included in the API request**, no prompt can force the model to preserve the product accurately.
